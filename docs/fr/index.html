Un raccourci vers l’essentiel

Moins de menus.
Plus de « ah, le voilà ».

Moodle a vos cours. Votre assistant a la conversation. MCP fait le lien entre les deux.

01 / RETROUVER

Le bon fichier, enfin.

Listez vos cours et cherchez un document par son nom. Un support précis, sans télécharger tout le semestre.

02 / COMPRENDRE

Un PDF, une conversation.

Transmettez le texte extrait d’un PDF choisi à votre assistant. Jusqu’à 12 000 caractères pour commencer à en parler.

03 / GARDER

À la bonne place.

Téléchargez depuis la CLI. Avec le client Mac optionnel, recevez aussi les fichiers de votre VPS dans vos dossiers.

Le premier pas est petit

Un terminal.
On vous guide.

Le setup demande l’URL de votre université, ouvre la connexion Moodle et vous aide à configurer le tunnel. Pas besoin de token Moodle.

# Python 3.11+ · macOS / Linux
$ git clone https://github.com/edouaz/moodle-mcp.git
$ cd moodle-mcp
$ bash setup.sh --lang fr
